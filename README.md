# Gestor de Calificaciones 📊

Módulo en Python para procesamiento, cálculo y validación de calificaciones académicas individuales y grupales.

## Características

- Validación de rangos de notas (0.0 a 5.0) y casos borde.
- Cálculo de promedios, valores extremos y estados académicos.
- Generación de resúmenes por estudiante y métricas de desempeño grupal.
- Suite de pruebas unitarias automatizadas con `pytest`.

## Ejecución y Pruebas

```bash
# Instalar dependencias
pip install -r requirements.txt

# Correr pruebas unitarias
pytest tests/
```
